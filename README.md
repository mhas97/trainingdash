## Importing activities

Use the **↑ import** button to load your Garmin data:

- **GPX** - export a single activity from Garmin Connect (open the activity → ··· menu → Export to GPX). Opens the log form pre-filled so you can review before saving.
- **Activities** - go to https://connect.garmin.com/app/activities?activityType=All, click **Export** (top right) to download `Activities.csv`, then import all activities in one go.
